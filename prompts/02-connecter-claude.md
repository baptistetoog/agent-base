# 2. Votre abonnement Claude fait tourner l'agent

**Ce qu'on explique (1 minute) :** vous avez déjà votre abonnement Claude (Pro ou Max). C'est lui qui fait réfléchir l'agent : pas de clé API à payer en plus, pas de compte à créer. À l'étape 5, dans l'outil, vous cliquez sur « Se connecter avec Claude », vous autorisez, vous recopiez le code affiché : c'est tout, aucun Terminal.

**Ce qu'il faut savoir :**
- l'agent consomme votre abonnement comme si vous parliez vous-même à Claude ; les automatisations aussi ;
- vous pouvez le déconnecter à tout moment (Réglages › Claude › Déconnecter) ;
- **ne jamais coller un code ou une clé dans une discussion avec Claude** : uniquement dans l'outil.

**Solution de secours** (si la connexion dans l'outil ne passe pas) : dans le Terminal de son ordinateur, `claude setup-token`, puis on colle la clé `sk-ant-oat01-…` obtenue dans « J'ai déjà une clé ».
