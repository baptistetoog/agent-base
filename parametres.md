# Les paramètres de votre agent

Remplissez la colonne « Valeur », puis lancez `python3 outils/rendre.py parametres.md`.
Les prompts prêts à coller sont créés dans `mes-prompts/`.

| Paramètre | Valeur | À quoi il sert |
|---|---|---|
| IP | 31.56.85.157 | l'adresse IP de votre VPS (dans le mail de l'hébergeur) |
| UTILISATEUR | agents | l'utilisateur du serveur qui fait tourner l'agent (minuscules, sans espace) |
| PORT | 4920 | le port local de l'outil (libre sur le serveur) |
| DOMAINE | agents.lecrystana.com | le sous-domaine de l'agent |
| EMAIL_ADMIN | baptiste@toog-app.com | votre compte admin dans l'outil |
| NOM_OUTIL | Espace agent | le nom affiché en haut de l'outil |
| NOM_AGENT | Mon agent | le nom de l'agent |
