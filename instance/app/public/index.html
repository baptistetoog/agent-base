      Connecter Claude

      L'agent travaille avec votre abonnement Claude. Trois étapes, environ deux minutes.

      1. 1

        Sur votre ordinateur, ouvrez le Terminal et tapez cette commande :

        claude setup-token
      2. 2

        Votre navigateur s'ouvre : connectez-vous à votre compte Claude (Pro ou Max) et cliquez sur Autoriser. Copiez le code affiché et collez-le dans le Terminal.

      3. 3

        Le Terminal affiche une clé qui commence par sk-ant-oat01-. Copiez-la et collez-la ici :

        🔒 La clé est rangée dans le coffre du serveur. Elle ne sera plus jamais affichée. Ne la collez jamais dans une discussion.
